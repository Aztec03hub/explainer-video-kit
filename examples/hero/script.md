### Hook @0-13
[curious] Everything you're watching was made by a Claude Code plugin called explainer-video, from one script and a few screens. The voice, the cursor, the subtitles, the camera. No screen recording. No editing.

### Cursor @13-22
Point it at your app's screens, and Claude plans every move. The cursor glides, it clicks, and the screen changes right on cue.
> shot: cursor to Runs, click, table appears

### Callouts @22-28
Brackets and a tag lock onto the button or number you name. If the layout moves, they move with it.
> shot: callout on the status column, tag Needs review

### Camera @28-35
Then the camera moves in. A smooth pan across the table, a zoom into one number, and back out.
> shot: eased pan and zoom

### Music @35-44
The subtitles land on the exact word I'm saying. And hear the music dip when I talk? It drops under the voice every time, and the video won't build if it doesn't.
> shot: detail screen, callout on the subtitles

### Voice @44-51
It doesn't sound like a robot, either. [whispers] Mark a line soft... [excited] or mark it big, and the voice acts it out.
> shot: settings voice section

### Gates @51-61
And it checks its own work. Two screens blurring into each other? Flagged. Text that should never be on screen? Caught. Fix it, and it passes.
> shot: terminal, gates fail then pass

### Install @61-70
Want to make your own? Start by installing it. Two commands in Claude Code, then run setup once. It fetches everything it needs to render.
> shot: terminal, two install lines then ev setup

### The key @70-81
The voice comes from ElevenLabs, so you bring your own key. Keep it in a key file, never in a chat. No key yet? Everything except the voice still works.
> shot: terminal, key file and ev doctor with and without a key

### Ask @81-87
Then open Claude Code in your project, and ask for an explainer video. [curious] That's the whole prompt.

### The flow @87-98
Claude writes the script and checks it. It captures your screens. It shows you the voice cost before it spends a credit. Then it records, adds the subtitles, and renders.
